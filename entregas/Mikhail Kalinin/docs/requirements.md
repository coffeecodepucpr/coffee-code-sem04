# Project Requirements

## Problem

The lack of a centralized platform for convenient discovery of educational programs and direct interaction between teachers and students.

## Target Audience

Teachers (course creators) and students (learners).

## Functional Requirements

- The system must allow users to register and select a role (teacher or student).
- The system must enable account login using a username and password.
- The system must allow teachers to create and utilize educational programs.
- The system must allow students to browse the catalog of available subjects on the dashboard.
- The system must enable students to select a suitable program and a specific teacher.
- The system must display user information and a list of subjects they study or teach in the profile.

## Non-Functional Requirements

- The system must ensure secure password storage and personal data protection.
- The system must have an intuitive and responsive web interface.
